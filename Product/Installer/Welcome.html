Install or update Pasu FS

Quit Pasu FS normally before continuing. Protection continues while its system extension remains active. Do not use “Stop Protection and Quit” for an update.

This package installs Pasu FS in Applications and a maintenance service that runs on demand for uninstalling. Existing protection rules, compatibility settings, audit records, and login preferences are kept.

This is a local test package containing development-signed software for registered test devices. It is not a notarized distribution installer.
