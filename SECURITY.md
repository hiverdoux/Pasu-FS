# Security policy

Pasu FS is source software for entitled developers and registered test devices.
It has no generally distributed, notarized release or supported production
release series. Read the [security boundaries](docs/threat-model.md) before use.

Report security problems through this repository's **Security → Report a
vulnerability** page. Do not put sensitive details in a public issue.

Include the affected source revision or app version, macOS version, steps to
reproduce the problem using synthetic files, and the expected and observed
behavior. Remove personal file paths, credentials and unrelated log entries.
Do not include provisioning profiles or private signing keys.

A report should distinguish a source-level concern from a reproduced behavior.
Receiving a report does not imply that a fix or response deadline is guaranteed.
