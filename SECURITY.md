# Security Policy

Pasu FS is a design-stage project. No Pasu FS binary has been released, and
this repository contains design documents and prototype source, so there are
no supported product versions yet.

## Reporting

If you find a security-relevant problem in the published design, prototype
code, or documentation, use GitHub private vulnerability reporting on this
repository (Security tab → Report a vulnerability).

Please do not open a public issue for a security report. Reports are read by
the project owner and will be acknowledged as quickly as possible.

Because the project has not shipped, reports about the planned design are also
welcome and will be treated as design-review input for the
[architecture](docs/architecture.md) and [threat model](docs/threat-model.md).
